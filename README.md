# zenselection

Hide the selection pane or dynamically adjust its length as you select paths.

This plugin works with the default layout config. If you use a plugin that modified the default layout, you will need to pass the right vertical layout object, that contains `Selection` as its first element and possibly `HelpMenu` as the second explicitely.
